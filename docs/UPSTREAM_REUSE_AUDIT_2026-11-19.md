## Concrete component selection
1. Keep Worthkind Flow's own **FastAPI domain API**, local enquiry business invariants and source-of-truth labels; move to PostgreSQL and real staff identity in M1.
2. For **hotel owner/staff frontend**, build original Worthkind Flow pages, optionally reusing individually audited **MIT shadcn/ui** components. Do not ship Kiranism template data or copy third-party visual assets.
3. For **human inbox**, first extend own case/ticket queue; integrate Chatwoot as an external service via approved scoped API only if pilot interviews require omni-channel handling.
4. For **notifications**, build only one verified provider adapter + inbound signed status webhook/outbox now. Consider Novu if multiple providers, scheduling and fallbacks justify independent deployment.
5. For **metering/AI**, evaluate OpenMeter and Langfuse only after paid agent usage is functional, privacy reviewed and costs benchmarked.
6. For **booking**, treat Hotel OS and hotel PMS as separate authorized sources. Read openstay/QloApps/Kamra for concepts, not blanket code reuse.

## Security and operational due diligence before source import
- **Repo source seen** is not a security assessment. Lock exact commit versions, run dependency/SBOM/secret/license scans, check advisories and transitive licenses, then test actual deployment and rollback.
- **Open-source license != rights to names/assets:** retain upstream copyright, notice files and modifications, and don't copy trademarks/screenshots/logos without permission.
- **Separate remote-provider terms:** WhatsApp, payment, PMS, telephone, email and AI providers have their own onboarding, approval and costs. Self-hosted code does not waive provider rules.
- **Commercial license legal review:** OSL-3.0/AGPL-3.0 network source requirements, mixed MIT/enterprise scopes and third-party modules need professional review before copying or forking; isolated API integration may be a distinct legal/engineering approach.
- **Compatibility:** current prototype is FastAPI/SQLite; target managed PostgreSQL is proposed; Hotel OS and Zuvamo are separate projects. Do not pretend third-party Ruby, PHP, Frappe or Go apps have been imported.
- **Real usage:** no above candidate was cloned, installed, started or integration-tested in Worthkind Flow during this audit.
